# Gerenciamento de Permissões no Linux

## 1. Introdução
Este projeto demonstra o gerenciamento de permissões de arquivos e diretórios em sistemas Linux, com foco em segurança defensiva e boas práticas de controle de acesso.

O controle adequado de permissões é essencial para evitar acessos não autorizados, elevação de privilégios e comprometimento de sistemas.

---

## 2. Objetivo
Demonstrar a utilização de comandos Linux para:
- Visualizar permissões
- Modificar permissões
- Alterar proprietários
- Restringir acessos indevidos

---

## 3. Ferramentas Utilizadas
- Linux (Kali Linux / Ubuntu)
- Terminal
- Comandos: ls, chmod, chown, chgrp
